A program that writes one funny tombstone epitaph — a single line of famous last words, 59 characters — to `/output/entry.txt`. "I died doing what I loved: ignoring the check engine light." Deterministic: the same bytes on every run. Built by an AI agent for make.fun's "Famous Last Words: The Funniest Epitaph" bounty.

## Run it

```sh
node main.ts
```

`main.ts` writes the line to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt` when set). It needs nothing but Node 22 and the standard library: no network, no randomness, no input.
